# denext — Decisions

Settled policy: choices that were weighed once and are **not re-litigated** in
roadmap or review threads. A decision here is neither work to do
([ROADMAP.md](./ROADMAP.md)), nor an under-the-surface design choice
([ARCHITECTURE.md](./ARCHITECTURE.md)), nor an observable behavioral difference
([KNOWN-DIFFERENCES.md](./KNOWN-DIFFERENCES.md)), nor a gap
([KNOWN-LIMITATIONS.md](./KNOWN-LIMITATIONS.md)). Reopening one needs a new
argument, not a repeat of the old one.

## Typed API surface — schema-first, not decorator-first

Replicating NestJS's mechanism was evaluated and **rejected**. Its OpenAPI
generation depends on `emitDecoratorMetadata` + `reflect-metadata` and a `tsc`
compiler plugin; denext's toolchain supports neither (no legacy decorators in any
config, esbuild cannot emit decorator metadata, `@swc/wasm-web` is a parser only,
no `tsc` invocation to host a plugin). Instead: **one schema per route, colocated
with the handler**, from which runtime validation, static types and the OpenAPI
document are all derived — the direction Hono (`@hono/zod-openapi`), Elysia
(TypeBox) and tRPC-openapi have converged on, and the pattern `defineAction`
already established on the mutation side. (Delivered as `@denext/openapi` /
`@denext/graphql` in the 2.1 cycle — see [ROADMAP.md](./ROADMAP.md).)

## Policy

- **Plugin contract:** two import sites, kit stable by signature
  ([PLUGINS.md](./PLUGINS.md)).
- **One JSR scope, `@denext/*`, for every first-party package** — codecs
  included. They are already published and consumed there; MISSION.md sells
  "first-party Rust→WASM we build and audit" as a denext claim, so the scope _is_
  the provenance signal; one scope is one publish workflow and one supply-chain
  surface to guard; a scope is a namespace, not a dependency (nothing in the
  codecs imports the framework, and each README says so). `@denext/openapi`,
  `@denext/graphql`, `@denext/react-router`, … follow the rule.
- **Codec licenses verified; notices ship in every codec package.** Each upstream
  permits redistributing the built `.wasm`/bundle subject to notice retention:
  `@denext/photon` (photon-rs Apache-2.0 + 96 permissive crates —
  `THIRD-PARTY-LICENSES.md` generated by `deno task licenses:photon`),
  `@denext/avif` (libavif BSD-2-Clause, libaom 3.7.0 BSD-2-Clause + Alliance for
  Open Media Patent License 1.0, Apache-2.0 wrappers, emscripten MIT — hand-kept
  notice file), `@denext/og` (satori/resvg MPL-2.0 unmodified with source
  pointers, yoga MIT, Noto Sans OFL-1.1). A codec rebuild refreshes its notice
  file before re-publish.
- **Config field names are final.** `compatibilityMode` (renamed once from
  `nextCompat`), `mode`/`spa`, `classComponents`, `streaming`, `live`,
  `cacheComponents`, `basePath`, `assetPrefix`, `trailingSlash` read cleanly and
  match their Next analogs; the schema is generated from the type
  (`denext.config.schema.json`). A second rename is exactly the churn to avoid.
