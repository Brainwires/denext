# Changelog

`@denext/docs-corpus` uses its own semver: a new patch version whenever the generated corpus's
content changes (see [README](./README.md#versioning)).

## 0.1.0

- First release: the corpus that `src/mcp/docs-corpus.ts` carried inside `@denext/denext`, moved
  into its own package to keep denext clear of JSR's 20 MiB package cap.
